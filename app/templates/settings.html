Jadwal Sinkronisasi Blocklist

Seberapa sering fetch_trustpositif.py download ulang daftar domain dan rebuild database LMDB yang dipakai modul Python (pymod) untuk blokir. Makin sering, makin cepat domain baru dari Komdigi ikut terblokir, tapi juga makin sering ada jeda singkat saat Unbound restart menerapkan data baru.

Mode Blokir TrustPositif

Catatan: redirect hanya bekerja mulus untuk HTTP biasa. Untuk situs HTTPS, browser akan menampilkan peringatan sertifikat karena nama domain di sertifikat tidak cocok dengan halaman blokir — ini keterbatasan bawaan semua DNS-based filtering, bukan bug di sini.

Mode Resolusi
SafeSearch Enforcement

Memaksa mode pencarian/konten aman bawaan tiap provider, memakai mekanisme resmi masing-masing (bukan lewat blocklist) — Google/YouTube/DuckDuckGo lewat CNAME ke endpoint SafeSearch resmi mereka, Bing lewat IP strict SafeSearch resmi Microsoft. Berlaku untuk domain utama tiap provider yang paling umum dipakai; tidak menjamin cakupan 100% semua subdomain/ccTLD yang ada.

Keamanan & Privasi
Kontrol Akses

Satu baris = satu rentang IP. Tambah baris baru untuk menambah entri, hapus barisnya untuk menghapus - tidak perlu pusing dengan koma.
